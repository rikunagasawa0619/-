# 横浜高島屋 販売商品リスト — 在庫管理システム

Google スプレッドシート + Apps Script による在庫管理・売上登録システム。

## セットアップ手順

### 1. スプレッドシートの準備

Google スプレッドシートで以下の **3つのシート** を作成してください。

#### シート「商品一覧」

1行目にヘッダーを設定し、2行目以降に商品データを入力します。

| 商品コード | シリーズ | サイズ | 商品名 | 金額(本体) | Men's/Women's | 残数 | 備考 |
|------------|----------|--------|--------|-----------|---------------|------|------|
| D3001 | Classic | M | ロングスリーブシャツ | 8800 | Men's | 10 | |
| D3002 | Classic | L | ロングスリーブシャツ | 8800 | Men's | 5 | |

- **商品コード** はユニークにしてください（主キー）
- **残数** は 0 以上の整数

#### シート「販売データ」

1行目にヘッダー、2行目にテンプレ行（書式・入力規則のコピー元）を設定します。

| 販売時刻 | 商品コード | シリーズ | サイズ | 商品名 | 金額(本体) | Men's/Women's | 残数 | 備考 |
|----------|-----------|----------|--------|--------|-----------|---------------|------|------|
| （テンプレ行：書式設定のみ。データは空でOK） | | | | | | | | |

- 2行目はテンプレ行です。ドロップダウンや書式を設定しておくと、売上登録時に自動コピーされます
- 3行目以降にデータが自動追記されます

#### シート「売上ボタン」

操作UIとして使用します（後述の図形ボタンを配置）。

### 2. Apps Script の設定

1. スプレッドシートを開く
2. メニュー → **拡張機能** → **Apps Script** を選択
3. デフォルトの `コード.gs` の内容をすべて削除し、本リポジトリの **`Code.gs`** の内容を貼り付け
4. 左側パネルの **＋** → **HTML** をクリックし、ファイル名を `Sidebar` にする
5. 作成された `Sidebar.html` に本リポジトリの **`Sidebar.html`** の内容を貼り付け
6. 左側パネルの歯車アイコン（プロジェクトの設定）→ 「`appsscript.json` マニフェストファイルをエディタで表示する」にチェック
7. `appsscript.json` を開き、本リポジトリの内容で上書き
8. **Ctrl+S**（保存）

### 3. 図形ボタンの配置（売上ボタンシート）

1. 「売上ボタン」シートを選択
2. メニュー → **挿入** → **図形描画** を選択
3. テキストボックスや四角形を追加し「売上パネルを開く」等の文字を入力
4. 「保存して閉じる」
5. シート上に表示された図形を右クリック → **スクリプトを割り当て**
6. `showSalesSidebar` と入力してOK

### 4. 初回実行と承認

1. スプレッドシートを**再読み込み**するとメニューに「**売上**」が表示されます
2. 「売上」→「売上パネルを開く」をクリック
3. 初回のみ Google の承認画面が表示されます
   - 「詳細」→「（安全でないページ）に移動」→「許可」で承認

## 使い方

1. 「売上ボタン」シートの図形ボタン、またはメニュー「売上」→「売上パネルを開く」をクリック
2. 右側にサイドバーが開き、商品一覧が表示されます
3. 検索バーで商品コードや商品名を入力して絞り込み
4. 数量を指定（デフォルト1）して「売上登録」ボタンをクリック
5. 販売データに1行追記され、商品一覧の残数が減算されます

## 注意事項

- 在庫（残数）が 0 の商品は売上登録できません（ボタン無効化）
- 同時操作に対応するためロック制御を実装しています
- 列の順序は固定していません。ヘッダー名で自動判別します
- 販売データの時刻列は「販売時刻」「売上時刻」「日時」のいずれかに対応します
